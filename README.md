


# RapidSpec

RapidSec is a simple ASP.NET WebApp for storing and displaying specs (Model Name, Engine type/size, Average Price, etc) of Super Cars in a Cloud Database. This app will use a AWS (Amazon Web Service) cloud database to store all of the information displayed in this web app.


## Instructions for Build and Use

Steps to build and/or run the software:

1. Clone the project from GitHub
2. Open the RapidSpec.sln
3. You should then be able to run the app

Instructions for using the software:

1. Create an account
2. Click the "Confrim Email" link
3. You can then sign in
4. Navigate to the Cars page
5. Click the Add Car button
6. Fill out the informaion of your desired vehicle
7. Click the submit button at the bottom of the form
8. From the main list of vehicles, you are able to Delete or Edit each vehicle

## Development Environment 

To recreate the development environment, you need the following software and/or libraries with the specified versions:

* You will need to create a asp.net MVC project in Visual Studio
* A few NuGet packages such as Microsoft.Data.SqlClient, Microsoft.EntityFrameworkCore.SqlServer, and Microsoft.AspNetCore.Identity.UI
* You will also need to downlad Amazon ToolKit from the AWS Website
